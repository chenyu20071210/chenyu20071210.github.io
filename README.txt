# 3D汉诺塔游戏作业说明

## 1. 项目功能
- 汉诺塔基础玩法：点击选中盘子，再点击目标柱子移动
- 自动通关：点击「自动通关」按钮，程序会用递归算法自动解出答案
- 移动计数：记录玩家/自动模式的移动步数
- 重置功能：一键重置游戏状态
- 错误提示：大盘放小盘时会给出文字警告

## 2. 操作说明
1.  输入框修改盘子数量（3-8个）
2.  点击「重新开始」生成对应数量的盘子
3.  手动玩：先点盘子选中，再点目标柱子移动
4.  自动玩：直接点「自动通关」，程序会自己完成

## 3. 技术实现
- HTML：搭建游戏结构和控制界面
- CSS：实现3D视角、渐变、阴影效果和盘子样式
- JavaScript：用数组和对象管理游戏状态，实现递归自动解、点击事件和规则判断
